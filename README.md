# Java OOP: Product Catalog and Search

![Java CI](https://github.com/aaminter/OOP/actions/workflows/ci.yml/badge.svg)

Учебное консольное приложение на Java, развивающее модель каталога и корзины интернет-магазина.

## Реализованные концепции
- базовая модель товара и специализированные типы товаров;
- фиксированная цена и скидочные товары;
- корзина и операции с товарами;
- поиск по каталогу и сравнение результатов;
- собственные исключения для некорректных цен и скидок;
- интерфейсы и компараторы для поиска.

## Технологии
Java, объектно-ориентированное программирование, наследование, полиморфизм, интерфейсы, коллекции и исключения.

## Запуск
Требуется JDK. Запустите org.skypro.skyshop.App в IntelliJ IDEA.

## Статус
Учебная консольная модель. Не содержит полноценного backend API, БД или пользовательской авторизации.
